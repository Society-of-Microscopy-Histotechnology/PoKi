# PoKi

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21708120.svg)](https://doi.org/10.5281/zenodo.21708120)

PoKi is a desktop application for viewing and analyzing video recordings of behavioral experiments involving laboratory animals.

## Repository scope

This repository contains public documentation and citation metadata for PoKi. The application source code, executable files, experimental videos, and research data are not included.
